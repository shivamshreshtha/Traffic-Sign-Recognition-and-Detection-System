# Deep Learning Models

This directory stores trained model checkpoints and weights for the **Traffic Sign Recognition and Detection System** developed under the guidance of IBM:
- **CNN Classifier (Model v5.0)**: Selected production architecture trained on GTSRB (97.90% validation accuracy across 43 classes).
- **YOLOv8 Detection Weights**: Fine-tuned on the GTSDB dataset for real-time bounding box extraction.
